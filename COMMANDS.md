# RDang — Инструкция по командам

Все команды начинаются с префикса `/rdang` (или алиасов: `/jd`, `/rd`, `/dang`, `/dungeons`).

## Основные команды

| Команда | Описание | Права |
|---|---|---|
| `/rdang menu` | Открыть визуальное GUI-меню управления данжами и аренами | `jamdungeons.admin` / `rdang.admin` |
| `/rdang list` | Список всех активных сессий данжей и их координат | Любой игрок |
| `/rdang rewards` | Забрать накопившиеся награды (монеты, кейсы, предметы) | `jamdungeons.claim` / `rdang.claim` |
| `/rdang spawn self` | Заспавнить случайный настроенный данж рядом с собой (30–150 блоков) | `jamdungeons.admin` / `rdang.admin` |
| `/rdang spawn <id> [site]` | Заспавнить конкретную арену по её ID (на случайной или заданной площадке) | `jamdungeons.admin` / `rdang.admin` |
| `/rdang spawn <количество> [мир]` | Заспавнить N данжей в случайных точках мира | `jamdungeons.admin` / `rdang.admin` |
| `/rdang stop [id]` | Остановить активный данж, удалить мобов и восстановить ландшафт | `jamdungeons.admin` / `rdang.admin` |
| `/rdang undo [id]` | Откатить данж или ручную вставку схемы (восстановить блоки из бэкапа) | `jamdungeons.admin` / `rdang.admin` |
| `/rdang schem <файл> [ignoreAir]` | Вставить схему (.schem/.nbt) на текущей позиции с защитой ландшафта | `jamdungeons.admin` / `rdang.admin` |
| `/rdang schem list` | Показать список доступных файлов схематик в папке `schematics/` | `jamdungeons.admin` / `rdang.admin` |
| `/rdang autospawn on` | Включить периодический автоспавн данжей по расписанию | `jamdungeons.admin` / `rdang.autospawn` |
| `/rdang autospawn off` | Выключить автоспавн данжей | `jamdungeons.admin` / `rdang.autospawn` |
| `/rdang autospawn interval <мин>` | Задать интервал между автоспавнами в минутах | `jamdungeons.admin` / `rdang.autospawn` |
| `/rdang autospawn status` | Показать текущий статус автоспавна, таймер и отложенные спавны | `jamdungeons.admin` / `rdang.autospawn` |
| `/rdang autospawn spawn` | Немедленно инициировать попытку автоспавна | `jamdungeons.admin` / `rdang.autospawn` |
| `/jd schedule list` | Список отложенных и фиксированных спавнов (до 10 слотов) | `jamdungeons.admin` / `rdang.autospawn` |
| `/jd schedule add <время> [арена]` | Добавить отложенный спавн (примеры: `14:30`, `+30m`, `+2h`, `once +45m`) | `jamdungeons.admin` / `rdang.autospawn` |
| `/jd schedule remove <номер>` | Удалить отложенный спавн по его номеру в списке | `jamdungeons.admin` / `rdang.autospawn` |
| `/jd schedule toggle <номер>` | Включить или выключить отложенный спавн | `jamdungeons.admin` / `rdang.autospawn` |
| `/jd schedule clear` | Очистить все отложенные спавны | `jamdungeons.admin` / `rdang.autospawn` |
| `/rdang give key <ник> [кол-во]` | Выдать ключ от наградного сундука игроку | `jamdungeons.admin` / `rdang.admin` |
| `/rdang give compass <ник> [кол-во]` | Выдать компас данжа, указывающий на активный сундук | `jamdungeons.admin` / `rdang.admin` |
| `/rdang reload` | Перезагрузить конфигурации (`config.yml`, `themes.yml` и др.) | `jamdungeons.admin` / `rdang.admin` |
| `/rdang status` | Показать статус WorldEdit, баз данных, экономики и регионов | `jamdungeons.admin` / `rdang.admin` |

## Смещение схематики после установки (вверх, вниз, влево, вправо)

После установки схематики её можно плавно и точно двигать на любое количество блоков как через интерактивное **GUI-меню**, так и через **команды**. При перемещении оригинальный ландшафт на старом месте восстанавливается из бэкапа, а постройка плавно вставляется на новые координаты без зависаний сервера.

### Управление через GUI-меню:
1. Откройте меню арены: `/jd edit <id или название>` (или через `/jd menu` -> клик по арене).
2. Нажмите на иконку поршня: **«Смещение схематики / постройки»** (слот 38).
3. В открывшейся панели доступны:
   - ⬆ **ВВЕРХ (+Y)** / ⬇ **ВНИЗ (-Y)** — изменение высоты.
   - 🔼 **ВПЕРЁД** / 🔽 **НАЗАД** — смещение по линии взгляда игрока.
   - ⬅ **ВЛЕВО** / ➡ **ВПРАВО** — смещение перпендикулярно взгляду игрока.
   - **Выбор шага**: быстрые кнопки на 1, 2, 5, 10 блоков или ввод своего точного значения через чат.
   - Игрок, находящийся внутри постройки, плавно перемещается вместе со схематикой.

### Управление через команды:
Поддерживается указание арены **как по ID, так и по названию** (включая названия с пробелами).

```bash
# Поднять схематику арены на 2 блока вверх
/jd move test_arena вверх 2
/jd move "Большая Арена" up 2

# Опустить схематику на 1 блок в землю (по умолчанию 1 блок)
/jd move test_arena вниз
/jd move test_arena down 1

# Сдвинуть влево или вправо относительно вашего взгляда
/jd move test_arena влево 3
/jd move test_arena вправо 1

# Сдвинуть вперед или назад относительно вашего взгляда
/jd move test_arena вперед 5
/jd move test_arena назад 2

# Абсолютные направления (север, юг, восток, запад)
/jd move test_arena север 4
/jd move test_arena юг 2
/jd move test_arena восток 1
/jd move test_arena запад 3

# Точное смещение по осям X, Y, Z (<dx> <dy> <dz>)
/jd move test_arena 0 -2 0
/jd move test_arena 5 0 -3
```

## Преднастройка сдвига спавна схематики (заранее для каждой схемы)

Если схематика должна появляться в мире с заглублением в землю (например, подземный данж или подвал на 3-4 блока вглубь) или, наоборот, быть приподнята над грунтом/водой, вы можете **заблаговременно настроить постоянный сдвиг спавна** для конкретной схематики или арены.

При каждом спавне (случайном на карте, по расписанию, по таймеру автоспавна или через `/jd test` / `/jd spawn`) постройка **автоматически смещается на заданное количество блоков**. Все точки мобов, наградной сундук, выход и регион WorldGuard синхронно размещаются на правильных координатах.

### Настройка через интерактивный GUI:
1. **Через меню арены**:
   - Введите `/jd edit <арена>` (или выберите в `/jd menu`).
   - Нажмите на слот 39: **«Преднастройка сдвига спавна»** (иконка загрузочной воронки).
   - В открывшемся меню нажимайте кнопки:
     - ⬆ **ВВЕРХ (+Y)** / ⬇ **ВНИЗ (-Y)** — изменение базовой высоты спавна (например, сделать глубже в грунт на 3 блока).
     - 🔼 **ВПЕРЁД** / 🔽 **НАЗАД** / ⬅ **ВЛЕВО** / ➡ **ВПРАВО** — горизонтальный сдвиг.
     - **Шаг кнопок**: быстрое переключение на 1, 2, 5, 10 блоков или ввод своего значения.
     - **Сбросить в 0**: мгновенный возврат к стандартной высоте земли.
     - **Сохранить для файла схематики**: сохраняет сдвиг как стандартный для самого файла схемы в `config.yml`.
     - **Тестовый спавн**: сразу запустить тест арены и проверить, как схема садится на рельеф.
2. **Через список файлов схематик**:
   - В меню арены нажмите **«Выбрать схематику»** (слот 28).
   - В списке файлов нажмите **ПКМ (правая кнопка мыши)** по любой схематике — откроется меню настройки сдвига для этого файла.
   - Любая арена, использующая этот файл схемы, автоматически унаследует настроенный сдвиг!

### Настройка через команды:

Поддерживается настройка как по **названию/ID арены**, так и по **имени файла схематики**:

```bash
# Просмотр текущего сдвига спавна для арены или файла схематики
/jd offset test_arena
/jd offset dungeon_castle.schem
/jd schematic offset "Лесной Данж"

# Открыть интерактивное GUI-меню сдвига спавна
/jd offset test_arena menu

# Сдвиг по высоте (самый частый случай: заглубление в грунт или приподнятие)
/jd offset test_arena вниз 3       # спавнить на 3 блока глубже в землю (Y: -3)
/jd offset test_arena down 4       # на 4 блока глубже
/jd offset test_arena вверх 2      # приподнять на 2 блока выше земли (Y: +2)

# Настройка непосредственно для файла схематики (применится ко всем аренам с этой схемой)
/jd offset dungeon.schem вниз 3
/jd schemoffset castle.schem down 2

# Сдвиг по сторонам горизонта или относительно взгляда
/jd offset test_arena влево 2
/jd offset test_arena вперед 3
/jd offset test_arena север 2
/jd offset test_arena юг 1

# Точный вектор смещения <dx> <dy> <dz>
/jd offset test_arena 0 -3 0       # ровно на 3 блока вниз по Y
/jd offset test_arena 2 -1 -3      # X: +2, Y: -1, Z: -3

# Сброс сдвига спавна в исходное состояние (0, 0, 0)
/jd offset test_arena reset
/jd offset dungeon.schem reset
```

## Установка воздуха и защита от застревания в блоках

По каждой отдельной арене можно индивидуально настроить, вставлять ли блоки воздуха из схематики:
- **С воздухом (`pasteAir: true`)**: пустоты и интерьеры комнат аккуратно вырезаются в ландшафте (горах, холмах, деревьях) и схематика не застревает в блоках мира. Оригинальный ландшафт сохраняется в бэкап и восстанавливается при `/rdang undo` или завершении события.
- **Без воздуха (`pasteAir: false`)**: вставляются только физические строительные блоки схемы, а воздух вокруг игнорируется. Это значительно ускоряет спавн и сохраняет естественный рельеф вокруг постройки.

**Управление режимом воздуха:**
- В GUI арены (`/jd edit <id>`): кнопка «Вставка воздуха: ВКЛ / ВЫКЛ».
- Командой: `/jd pasteair <id> on|off` или `/jd schematic air <id> on|off`.

## Оптимизация работы с блоками и схематиками (High TPS)

1. **Отключение физики и SideEffects при вставке**: WorldEdit и FAWE отключают проверку физики блоков (`SideEffectSet.none()`), предотвращая цепочечные обновления жидкостей, гравия и света.
2. **Асинхронная предзагрузка чанков Paper**: перед вставкой, очисткой или бэкапом все чанки области предзагружаются асинхронно через `world.getChunkAtAsync(...)`, полностью устраняя синхронные подвисания главного потока и просадки TPS до 1-2.
3. **Кэширование схематик**: файлы схем кэшируются в оперативной памяти и не парсятся заново с диска при каждом спавне или проверке.
4. **Умная очистка области**: при удалении или очистке заменяются только не-воздушные блоки через маску (`ExistingBlockMask`), пропуская существующий воздух и в разы снижая нагрузку.

## Примеры настройки отложенных спавнов (до 10 слотов)

```bash
# Просмотр всех настроенных отложенных спавнов
/jd schedule list

# Спавнить случайный данж каждый день в 14:30 и 20:00 (по Europe/Moscow)
/jd schedule add 14:30 any
/jd schedule add 20:00 any

# Спавнить конкретную арену "boss_pve" в 18:00
/jd schedule add 18:00 boss_pve

# Отложенный спавн через 45 минут
/jd schedule add +45m any

# Разовый отложенный спавн через 2 часа (выполняется один раз и отключается)
/jd schedule add once +2h any

# Включить/выключить или удалить слот #2
/jd schedule toggle 2
/jd schedule remove 2
```

## Примеры использования

```bash
# Быстрый спавн данжа рядом с собой для тестирования
/rdang spawn self

# Спавн ВСЕХ созданных данжей одновременно в разных точках мира
/rdang spawn all
# или /jd spawn all (также доступна кнопка в меню /jd слот 47)

# Остановка всех активных данжей
/rdang stop all
# или /jd stop all (кнопка в меню /jd слот 48)

# Ручная вставка схемы без уничтожения рельефа
/rdang schem my_dungeon.schem

# Отмена последней вставки или удаление данжа
/rdang undo

# Включение автоспавна каждые 45 минут
/rdang autospawn interval 45
/rdang autospawn on

# Проверка оставшегося времени до спавна
/rdang autospawn status
```

## Награды за данжи (PvP / PvE) и Яйца питомцев

Файл настроек: `plugins/RDang/rewards.yml`

### 1. Награды PvP данжей
- **Исключены имбалансные предметы**: шалкеры (`SHULKER_BOX`) и элитры (`ELYTRA`) полностью удалены из пула.
- **Ограничения на ценности**:
  - Панцирь шалкера (`SHULKER_SHELL`): максимум **1 шт.**, выпадает редко (`min: 1, max: 1`).
  - Алмазный блок (`DIAMOND_BLOCK`): максимум **1 шт.**, выпадает редко (`min: 1, max: 1`).
  - Тотем бессмертия (`TOTEM_OF_UNDYING`): максимум **1 шт.**, редкий.
- **Базовые и полезные предметы**:
  - Еда: жареная говядина (`COOKED_BEEF`), золотая морковь (`GOLDEN_CARROT`), хлеб (16–32 шт.).
  - Дерево: дубовые, еловые и берёзовые бревна (`OAK_LOG`, `SPRUCE_LOG`, `BIRCH_LOG`) по **16 шт.**
  - Расходники: стрелы (`ARROW`, 16–32 шт.), железо (`IRON_INGOT`), золото (`GOLD_INGOT`), пузырьки опыта (`EXPERIENCE_BOTTLE`), фейерверки, жемчуг эндера, золотые яблоки, алмазы (2–4 шт.).

### 2. Яйца питомцев
- Выпадают за победу в **PvP и PvE**:
  - **Legendary**: 10%
  - **Epic**: 25%
  - **Rare**: 75%
- При открытии или нажатии «Забрать всё» в сундуке награды яйцо выдается консольной командой:
  `/petadmin giveegg <ник> <epic/legendary/rare>`
- В меню сундука яйцо отображается как предмет с подсветкой редкости и лором.

## Сохранение шаблона постройки с очисткой мира

- В меню арены `/jd` кнопка **«Сохранить шаблон постройки»** (слот 23) или команда `/jd template save <id>`:
  1. Находит сундук и точки мобов, привязывая их к шаблону.
  2. Сохраняет блоки постройки в схематику `templates/<id>.schem` через FAWE.
  3. **Автоматически очищает площадь постройки в мире** (заменяет блоки постройки на воздух без дропа и лагов), освобождая место на карте.
